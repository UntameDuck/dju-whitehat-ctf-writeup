# Ping Masters

## 취약점 요약

IP/도메인 입력값이 서버의 `ping` 셸 명령에 직접 연결됐습니다. 명령 구분자 `;`로 두 번째 명령을 주입할 수 있었고, 공백 필터는 셸 변수 `${IFS}`로 우회했습니다.

## 탐색 과정

루트 디렉터리를 나열해 명령 실행 여부와 파일 구조를 동시에 확인했습니다.

```sh
127.0.0.1;ls${IFS}/
```

응답에서 `/secret_files_for_admin`이라는 비정상적으로 명확한 디렉터리를 발견했습니다. 이어서 디렉터리 목록과 파일 내용을 한 요청에서 확인했습니다.

```sh
127.0.0.1;ls${IFS}/secret_files_for_admin;cat${IFS}/secret_files_for_admin/TOP_SECRET_FLAG.txt
```

`TOP_SECRET_FLAG.txt`에서 플래그를 획득했으나, 원문에는 실제 값이 기록되어 있지 않습니다.

## 왜 `${IFS}`가 동작하는가

Unix 셸은 `IFS`를 단어 구분에 사용합니다. 입력 필터가 공백 문자만 제거하더라도, 셸 평가 단계에서 `${IFS}`가 구분자로 확장되기 때문에 `ls /`와 같은 인자 분리를 재구성할 수 있습니다.

## 대응

IP 주소를 셸 문자열에 결합하지 말고 인자 배열로 프로세스를 실행해야 합니다. 입력은 IP 주소 또는 허용된 도메인 형식으로 파싱하고, 셸 메타문자 차단을 보조 방어로만 사용해야 합니다.
