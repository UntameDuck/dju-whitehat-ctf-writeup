# 당신은 로봇입니까?

> [!NOTE]
> 원문은 취약점과 공격 체인을 요약한 상태입니다. 구체적인 요청 값과 플래그는 기록되어 있지 않습니다.

## 공격 체인

```text
robots.txt 정보 노출
 → /admin-beta/ 발견
 → view.php 소스 노출
 → LFI 및 필터 분석
 → upload.php의 2초 삭제 지연 확인
 → 웹셸 업로드와 즉시 실행을 병렬화
 → RCE 및 플래그 획득
```

## 핵심 판단

- `robots.txt`는 접근 제어가 아니라 크롤러 안내일 뿐입니다.
- `view.php?file=`가 사용자의 경로를 신뢰해 LFI가 발생했습니다.
- `flag` 문자열 필터는 표현·경로 변형으로 우회 가능한 블랙리스트였습니다.
- 업로드 후 2초 뒤 삭제하는 설계는 파일이 존재하는 짧은 시간 창을 만듭니다.
- 공격자는 업로드 요청과 실행 요청을 동시에 반복해 race window 안에서 코드를 실행할 수 있습니다.

## 대응

민감 경로는 인증·인가로 보호하고, 파일 선택은 서버 측 ID 허용 목록으로 제한해야 합니다. 업로드 파일은 검증이 끝날 때까지 외부에서 접근할 수 없는 임시 위치에 두고, 원자적으로 최종 위치로 이동해야 합니다. 업로드 디렉터리의 스크립트 실행도 금지해야 합니다.
