# 딩동게이트

## 문제를 조건식으로 바꾸기

서버는 한국 표준시 기준으로 다음 세 조건을 모두 만족할 때만 플래그를 출력합니다.

```text
(hour >= 15 OR hour < 1)
AND minute % 10 == 0
AND 0 <= second < 10
```

말로 표현된 “시간 게이트”를 정확한 논리식으로 환원하면 공격 자체는 단순한 타이밍 자동화 문제가 됩니다.

## 접근 전략

수동 접속은 네트워크 지연과 사람의 반응 시간 때문에 10초 창을 놓치기 쉽습니다. 로컬 표시 시간을 `Asia/Seoul`로 고정하고, 0.2초마다 조건을 검사해 열린 순간 `nc`를 실행하도록 자동화했습니다.

```bash
export TZ=Asia/Seoul
date '+%Y-%m-%d %H:%M:%S %Z'
```

재현 스크립트는 [`../scripts/dingdong-gate.sh`](../scripts/dingdong-gate.sh)에 있습니다.

## 검증과 실패 요인

- 시스템 시계가 실제 시간과 수 초 이상 어긋나지 않았는지 확인합니다.
- TCP 9014 아웃바운드 연결이 허용되는지 확인합니다.
- WSL/컨테이너에서는 상위 호스트의 시간 및 네트워크 정책도 확인합니다.
- 실행 결과를 파일로 보존한 뒤 다음 명령으로 플래그만 추출합니다.

```bash
grep -o 'FLAG{[^}]*}' timegate_out.txt
```

원문에는 플래그 획득 방법만 있고 실제 값은 기록되어 있지 않습니다.
