# fragments_of_memory

## 문제의 핵심

메모리 이미지에서 `FLAG{...}` 패턴을 검색하면 여러 후보가 발견됩니다. 이 문제는 단순히 첫 번째 플래그 형태를 제출하는 것이 아니라, 미끼를 배제하고 문맥상 유효한 값을 식별하는 문제였습니다.

## 후보 수집

대표적인 후보는 다음과 같았습니다.

```text
flag{m3m_puzzzl3_r3ass3mbly}
flag{m3m_puzzl3_r3ass3mby}
flag{mem_puzzle_reassembly}
FLAG{M3M_PUZZL3_R3ASS3MBLY}
```

## 판별 기준

- 대회가 요구하는 대소문자 형식과 일치하는가?
- `E → 3` 같은 leetspeak 치환이 전체 문자열에서 일관적인가?
- 후보 주변 메모리 문맥이 완전한 토큰을 지지하는가?
- 다른 후보가 의도적인 오탈자 또는 변형으로 설명되는가?

마지막 후보만 형식과 치환 규칙이 일관되었고 주변 메모리에도 명확한 완전 문자열로 남아 있었습니다. 나머지는 철자 오류 또는 의미가 다른 미끼로 판단했습니다.

## Flag

```text
FLAG{M3M_PUZZL3_R3ASS3MBLY}
```

첫 매치가 아니라 후보군 전체를 수집한 뒤 형식·문맥·일관성으로 순위를 매긴 것이 핵심입니다.
